# PythonQA
A study in hallucination detection in LLMs like ChatGPT. Provides a Jupyter Notebook framework for taking a document with subject matter specific information and testing hallucinations from an LLM answering questions about the text.

This study uses RAG and tests different types of RAG retrieval (sparse vs. ensemble) to reduce the rate of hallucinations in ChatGPT's responses to subject specific questions.
